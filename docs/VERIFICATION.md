# v0.901 배포 검수

| 구분 | 결과 |
|---|---|
| 동결 EXE | 실제 배포 EXE의 소스 일치·GUI 초기화·페이로드 해시 확인 |
| CHD 적용 | 원본 CHD → 결과 GDI/50트랙, 모든 결과 SHA-256 일치 |
| GDI 적용 | 원본 50트랙 GDI → 결과 GDI/50트랙, 모든 결과 SHA-256 일치 |
| 경로 | 한글·공백이 포함된 출력 경로에서 CHD 적용 완료 |
| 실패 처리 | 잘못된 원본/트랙·이미 적용한 이미지·폴더 덮어쓰기·경로 이탈·손상된 페이로드 등 9사례 확인 |
| 원본 보존 | 적용 후 원본 CHD SHA-256 동일, 오디오 47트랙 동일 |
| 게임 코드 | 테스트 63개, 글리프 픽셀 22,446개·메타데이터 조회 44,892회·조합 입력 14조건/84사례 확인 |
| UI/데이터 | 알려진 폭 조건 2,209개, 압축 스트림 243개와 원본 데이터 대조 통과 |
| 단체 이적 | 동일 목록의 반복 이동 108 → 5~9프레임, 첫 이동 13 → 1프레임 |

단체 이적은 180 VBlank 동안 같은 방향 입력으로 선수 목록 선택 인덱스를 읽었습니다.
처음 목록과 뒤쪽 185~212번 구간을 확인했고 전체 220명 이름·순서를 보존했습니다.
글자 폭/텍스처 존재 확인에 불필요한 비트맵 합성을 생략하여 개선했으며, 실제 렌더링 글리프와 캐시 크기는 유지합니다.
대상 단체 선택 조작의 별도 측정은 이 수치에 포함하지 않습니다.

검사 기록: [패처](patcher-verification.json), [단체 이적](transfer-performance.json).
실물 드림캐스트, VMU 저장 후 재부팅, 모든 기술의 개별 시전과 모든 UI 상태를 검증한 결과는 아닙니다.

BIOS 부팅 배치 문제와 GDI/CHD·OpenGL/Direct3D 확인은 [0.901 레트로아크 검수](RETROARCH.md)에 기록했습니다.
